## Log Entries

### Entry Format
- Agent: {name}
- Date: {date}
- Domain: {domain}
- Research tier: {1/2/3}
- Cost estimate: {$0.00 / $X.XX}
- Template used: {which template or "custom"}
- Blended from: {if blended, which templates}
- Q1 score: {N}/7 | Q2: {N}/7 | Q3: {N}/7 | Q4: {N}/7 | Q5: {N}/7
- Avg score: {N}/7
- Quality gate: structure {pass/fail} | knowledge {pass/fail} | notebook {pass/N/A}
- Agent rating: {1-5}
- Follow-ups needed: {which questions, what was missing}
- Template action: {appended new template / added variant / updated lessons / no change}
- Learning: {what prompt adjustment would improve results next time}
