**Discovery during user dog-food (Task 5):** No nudge appeared on /clear despite the hook firing correctly (proven via routing log + manual invocation producing correct JSON). Triage via [code.claude.com/docs/en/hooks](https://code.claude.com/docs/en/hooks) revealed Claude Code's per-event decision-control matrix:

- `SessionEnd` is "side effects only" — stdout `additionalContext` is silently discarded
- `PreCompact` only supports top-level `decision: "block"` — no context injection
- Both events D004 §6 named are exactly the two that can't inject context

D004 §6 adjudication missed this — the original adversarial review verified `additionalContext` exists as an API field but didn't check the per-event matrix. Adjudicated to v4.1 in D005 with a working architecture proposal (flag-file + SessionStart pickup).
