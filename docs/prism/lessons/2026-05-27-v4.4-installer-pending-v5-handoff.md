### Arc 2 — Auth pivot (Phase 5: `claude -p` instead of `fetch()` + API key)

User noted: "i am on claude code CLI not anthropic key" — this exposed a fundamental architecture mismatch. The Phase 3 hook used `fetch('https://api.anthropic.com/v1/messages')` with `x-api-key: ${ANTHROPIC_API_KEY}`, which requires a raw API key. Friends-only Claude-Code-plugin distribution = users have CC subscription, not API keys.

Pivoted the hook to `spawnSync('claude', ['-p', '--model', model], {input: combinedPrompt})` via stdin (avoids Windows ENAMETOOLONG on >32KB payloads). Added recursion guard via `PRISM_OOB_REVIEWER_PROCESS=1` env var. Doc sweep removed ANTHROPIC_API_KEY references from user-facing files. 2 commits: `69ffa3976` (code) + `8d553ded7` (docs).

Captured as new memory `[[feedback-prism-claude-p-auth-pattern]]`.
